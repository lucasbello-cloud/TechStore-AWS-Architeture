# Banco de Dados MySQL - TechStore

## Objetivo
Desenvolver um banco de dados relacional para uma loja virtual fictícia chamada TechStore.

## Tecnologias utilizadas
- Ubuntu Linux (WSL2)
- MySQL Server 8.4
- SQL

## Estrutura do banco
O banco de dados possui quatro tabelas principais:

- clientes: armazena os dados dos clientes.
- produtos: armazena produtos, preços e estoque.
- pedidos: registra os pedidos dos clientes.
- itens_pedido: relaciona produtos aos pedidos.

## Atividades práticas realizadas

- Criação do banco de dados TechStore.
- Criação de tabelas relacionais.
- Inserção de clientes e produtos fictícios.
- Cadastro de pedidos.
- Consultas SQL com SELECT e WHERE.
- Relacionamento entre tabelas com INNER JOIN.
- Atualização de estoque com UPDATE.
- Ordenação com ORDER BY.
- Funções COUNT, AVG e SUM.
- Criação de VIEW.
- Criação de INDEX.
- Backup do banco com mysqldump.
