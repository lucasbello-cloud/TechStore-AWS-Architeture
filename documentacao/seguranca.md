# Segurança da Infraestrutura - TechStore

## 1. Gerenciamento de acesso - IAM

O AWS IAM permite controlar quem pode acessar os recursos da AWS e quais ações cada identidade pode executar.

- Usuários: identidades individuais.
- Grupos: organização de usuários.
- Roles: permissões temporárias assumidas por serviços ou identidades.
- Policies: documentos que definem permissões.

## 4. Proteção de dados

- Amazon RDS: utiliza controles de acesso ao banco de dados.
- Amazon S3: permite configurar políticas de acesso aos arquivos.
- Criptografia: protege dados armazenados e em trânsito.
- Backups: ajudam na recuperação dos dados.


## 5. Conclusão

A segurança da TechStore é baseada no controle de acesso, princípio do menor privilégio, proteção da rede, criptografia e proteção dos dados.

Esta documentação representa uma proposta conceitual de segurança para uma infraestrutura AWS.
